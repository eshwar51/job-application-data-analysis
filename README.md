# Job Application Data Analysis

## Overview
This project analyzes job application data to identify hiring trends, application source performance, shortlisting patterns, and employer response times.

## Objectives
- Identify the best-performing application sources.
- Analyze the relationship between application completion and shortlisting.
- Compare response times between paid and unpaid roles.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Findings
- Referrals achieved the highest hiring conversion rate.
- Applicants completing all four steps had a significantly higher shortlisting rate.
- Paid roles received responses faster than unpaid roles.
